这个网站的所有内容都通过 GitHub 仓库管理。核心入口只有一个：**仓库 → Issues → New issue → 选择模板 → 填表提交**，剩下的交给机器人自动完成。

## 发布文章

1. 打开仓库的 Issues 页面，点击绿色按钮 New issue
2. 选择模板「发布文章」
3. 按提示填写：Issue 标题就是文章标题；摘要和标签可以留空；正文用 Markdown 书写，直接粘贴或拖入图片会自动上传显示
4. 点击 Submit new issue 提交
5. 约 1-2 分钟后，机器人会在这条 issue 里回复文章的访问链接，并自动关闭 issue

## 附带附件（可选）

发布文章时可以让读者直接下载附件（PDF / TXT / Markdown / EPUB 等任意格式），下载区会显示在文章标题下方，读者无需登录 GitHub：

1. 先上传文件：打开仓库的 public/attachments/ 目录 → 右上角 Add file → Upload files → 拖入文件 → Commit changes
2. 再用「发布文章」模板提交文章，在「附件」栏每行填一个文件名（须与上传的文件名一致）
3. 每篇文章还会自动提供「Markdown 原稿」下载，无需手动操作

进阶：`显示名|文件名` 可自定义下载项名称（如 `荒原|waste-land.txt` 显示为「荒原」）；填 `https://` 开头的完整网址可外链文件。忘记上传也没关系，机器人会在 issue 回复里提醒，之后补传文件即可，下次部署自动出现。

## 诗歌与诗体排版

正文里诗歌一行一句直接写（不需要任何特殊标记），网站会自动识别诗体段落，保留逐行换行、空行分节与行首缩进，效果与 GitHub 预览一致。例如这样写：

这是诗的第一行，
这是诗的第二行。

空行表示诗节之间的分隔。普通文章段落不受任何影响，长行也会自动折行不溢出。

## 修改文章

找到对应的那条 issue（已关闭的也可以），点击编辑，改完保存就会自动重新发布。

注意：要编辑 issue 本身。在 issue 下面添加评论是不会触发更新的。

## 上架电子书

1. 先上传 epub 文件：打开仓库的 public/books/ 目录 → 右上角 Add file → Upload files → 拖入 .epub 文件 → Commit changes
2. 回到 Issues → New issue → 选择模板「上架电子书」
3. 填写书名（issue 标题）、作者、年份、简介、EPUB 文件名；如需同时提供 epub 之外的附加文件（如译注 PDF），先传到 public/attachments/，再在「附加文件」栏每行填一个文件名
4. 提交后自动上架到网站的「阅读」栏目，支持在线阅读与下载

## 删除内容（少见操作）

在仓库网页里直接删除对应文件，删除提交后网站会自动重新部署：

- 文章：content/posts/issue-编号.md
- 书籍：content/books/issue-编号.json
- 附件：public/attachments/ 下的对应文件
